# Advanced Visitor Analytics

A WordPress plugin that tracks live visitors and user engagement metrics.

## Features

- Live visitor tracking
- Scroll depth tracking
- Session tracking
- Heatmap click simulation
- Admin analytics dashboard
- Lightweight frontend scripts

## Installation

1. Upload the plugin folder to:
   ```
   wp-content/plugins/
   ```

2. Activate the plugin from WordPress admin

3. Open:
   ```
   Visitor Analytics
   ```
   from the admin sidebar

## Folder Structure

```text
advanced-visitor-analytics/
│
├── advanced-visitor-analytics.php
├── includes/
├── assets/
│   ├── js/
│   └── css/
```

## How It Works

The plugin loads frontend tracking scripts that monitor:
- page visitors
- scroll activity
- click interactions
- basic session behavior

Data is displayed inside the WordPress admin dashboard.

## Requirements

- WordPress 5.0+
- PHP 7.2+
